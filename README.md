# AI Study Helper

AI Study Helper is a frontend-only Android app built with Kotlin, Jetpack Compose, Navigation Compose, Material 3, MVVM, and DataStore Preferences.

## Features

- AI Chat with local simulated responses
- Subjects list with local flashcards
- Flashcard question, answer, correct, and incorrect flow
- Saved study results using DataStore
- Results dialog with delete support
- Three bottom navigation tabs: AI Chat, Subjects, Results

## Run

Open the project in Android Studio and run the `app` configuration.

Command-line build:

```bash
JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home" ./gradlew :app:assembleDebug
```

The debug APK is generated at:

```text
app/build/outputs/apk/debug/app-debug.apk
```
